================================================================
        智能家居项目 —— 编译与部署说明
        （由「编译和部署必看.txt」+「编译和部署必看1.txt」合并整理）
================================================================

项目包含两个 Qt 工程：

    smartpro/       T113 终端设备（下位机）源码
    smartserver/    服务器 / 上位机源码，运行在虚拟机中

     前置条件：服务器与终端设备必须先能互相 Ping 通。
     虚拟机网络建议使用「桥接模式」。


----------------------------------------------------------------
一、服务器端（smartserver）代码修改
----------------------------------------------------------------

修改文件：smartserver/widget.h

定位到第 16-19 行，根据自己当前的网络配置进行修改：

    // 本机IP 当前运行在虚拟机上 所以为虚拟机的IP
    #define SELF_IP   "192.168.1.4"
    // 设备IP 为T113终端设备当前的IP
    #define DEVICE_IP "192.168.1.18"


----------------------------------------------------------------
二、终端（smartpro）代码修改
----------------------------------------------------------------

修改文件：smartpro/widget.h

定位到第 59-62 行，根据自己当前的网络配置进行修改：

    // 服务器 IP    虚拟机运行服务器时 为虚拟机ip
    #define SERVER_IP  "192.168.1.4"
    // 当前本机 IP   T113终端设备的当前IP
    #define SELF_IP    "192.168.1.8"


================================================================
三、终端（T113）需要部署的文件
================================================================

------------------------------------------------
1. 项目源码
------------------------------------------------
1) 复制到虚拟机环境下，使用 QtCreator 打开项目，并选择 T113 构建；
   构建完成后，将生成的 "smartpro" 文件拷贝到开发板。
2) 授予运行权限：

       chmod +x ./smartpro

------------------------------------------------
2. 第三方库
------------------------------------------------
文件位置：manual-deploy/thd.tar

1) 解压 "thd.tar" 文件，将所有文件上传至 "/usr/lib" 用户库文件夹。
2) 执行 ldconfig 刷新链接：

       ldconfig

------------------------------------------------
3. 人脸 AI 模型文件
------------------------------------------------
文件位置：manual-deploy/zeng_sim.onnx

1) "zeng_sim.onnx" 暂未使用。

------------------------------------------------
4. 人脸识别文件
------------------------------------------------
文件位置：manual-deploy/haarcascade_frontalface_default.xml

1) 将 "haarcascade_frontalface_default.xml" 拷贝到 "/root" 文件夹下。
2) 确认路径为：

       /root/haarcascade_frontalface_default.xml

------------------------------------------------
5. 音频文件
------------------------------------------------
文件位置：manual-deploy/pcm.zip

1) 创建音频文件夹：

       mkdir /tmp/pcm

2) 解压 "pcm.zip"，将文件拷贝至 "/tmp/pcm/" 文件夹下，
   可以直接使用工具上传。
3) 确认文件路径形式为：

       /tmp/pcm/*****.pcm

------------------------------------------------
6. 中文字体
------------------------------------------------
文件位置：manual-deploy/中文字体乱码问题.png

1) 如终端界面出现中文乱码，参考该截图处理。
